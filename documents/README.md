# README for documents

Human-consumption documents live here.

The LLM does not load these files as project rules.

## Index

- `00-pattern-of-interaction.md` — how to work with an LLM: work items, episodes, async, and review.
- `01-async-worktree.md` — worked example: run the LLM in its own git worktree and merge when the episode settles.
- `02-tool-universe.md` — a survey of LLM tools through the async and attention lens.
- `03-conversation-summary.md` — a summary of the conversation that produced these documents.
- `04-lessons-from-homelab.md` — lessons from the first real application of the skeleton.
- `05-lessons-from-MI25.md` — lessons from the MI25 fan-service project.
- `06-project-pages.md` — project-pages publishing conventions (summary; canonical version in the homelab).
- `07-prompt-maturity.md` — the 0–3 maturity rubric for the prompt protocol, and how to score it.

## How this project does it

- `10-vcard-format.md` — the vCard generations, the content-line grammar,
  folding, parameters, escaping, quoted-printable and base64 values, the
  structured names and addresses, and what this project does and does not yet do
  with them.
- `11-mime-type-association.md` — how a Linux desktop resolves a file type to an
  application, what `shared-mime-info` already defines for vCard, and exactly
  what this project writes to handle the type.
- `12-vcard-knowns-and-unknowns.md` — what is documented, observed, and only
  conventional about the format, what is genuinely unknown, and which decisions
  this project made where the format is silent.
- Documents `00` through `07` are the skeleton's, kept as they are.
